**PolicyChat AI** is a secure, AI-powered chatbot designed to extract insights and answer queries from complex documents (PDF, DOCX, PPTX).

### Key Features
- **Advanced NLP**: Leverages **Google's Gemini API** for accurate, context-aware responses.
- **Secure Authentication**: Implemented **Supabase authentication** for secure user sessions and persistent chat histories.
- **File Analysis**: Capable of processing and understanding complex policy documents.
- **Modern UI**: Built with React for smooth, device-friendly interactions.

This project demonstrates the integration of Large Language Models (LLMs) into practical, enterprise-grade applications.
